# IINA Library v0.13.1 — Public Beta

### Improvements
- TV Shows tab displays the number of shows, not the number of video episodes.
- Cleaner Settings layout with maintenance tools tucked into an Advanced section.
- Artwork appears as soon as the file finishes downloading; no IINA restart should be necessary.
- Refresh also retries missing metadata/artwork with a configured TMDB key.

### Unchanged
- Continue Watching, seasons, playback, manual matches, local cache and TMDB attribution.

### Install / update

IINA → Settings → Plugins → Install from GitHub → `monroedb/IINA-library`.

This is a public beta. Please report macOS and IINA version with reproducible issues. Do not post TMDB API keys or private folder paths.
